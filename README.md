Тема: Создать проект
Expo - это структура React Native, которая облегчает разработку приложений для Android и iOS. Наша структура обеспечивает файловую маршрутизацию, стандартную библиотеку нативных модулей и многое другое. Expo - это открытый исходный код с активным сообществом на GitHub и Discord.
Мы также делаем Expo Application Services (EAS), набор услуг, которые дополняют структуру Expo на каждом этапе процесса разработки.

Системные требования
    Node.js (LTS).
    Поддерживаются macOS, Windows (Powershell и WSL 2) и Linux.

Вместо проекта по умолчанию вы можете начать с одного из примеров Expo. Это небольшие приложения, каждое из которых демонстрирует определенную функцию или интеграцию, такие как Expo Router, Expo Widgets или экран камеры.
Чтобы просмотреть полный список и выбрать один в интерактивном режиме, запустите create-expo-app с --example Опция и отсутствие имени:
npx create-expo-app@latest --example
Чтобы создать известный пример напрямую, пропустите его имя:
npx create-expo-app@latest --example with-widgets

Настройте агента ИИ
Новый проект включает в себя контекстные файлы проекта, которые агенты ИИ читают: AGENTS.md, CLAUDE.md и .claude/settings.json. Клод Код и Codex также имеют официальный плагин Expo. С помощью одной команды вы можете установить Expo Skills и зарегистрировать сервер протокола контекста модели Expo (MCP):
claude plugin install expo@claude-plugins-official
codex plugin add expo@openai-curated
Затем войдите в свой аккаунт Expo:
codex mcp login expo

Тема: Начать развиваться
Запустите сервер разработки
Чтобы запустить сервер разработки, выполните следующую команду:
npx expo start
Откройте приложение на вашем устройстве
После выполнения команды выше вы увидите QR-код в вашем терминале. Отсканируйте этот QR-код, чтобы открыть приложение на вашем устройстве.
Если вы используете Android Emulator или iOS Simulator, вы можете нажать A или I Соответственно, чтобы открыть приложение.
Сделайте свое первое изменение
Откройте файл src/app/index.tsx в редакторе кода и внесите изменения.
src/app/index.tsx
     <ThemedView style={styles.heroSection}>
       <Анималый икона />
       <ThemedText type="title" style={styles.title}>
           Добро пожаловать в&nbsp;Expo
           Здравствуйте, Мир!
       </ThemedText>
     </ThemedView>
Структура файлов
Ниже вы можете ознакомиться со структурой файлов проекта по умолчанию:
src/приложение - Содержит навигацию приложения, которая основана на файле. Структура файлов в каталоге src/app определяет навигацию приложения.
Приложение имеет два маршрута, определенные двумя файлами: src/app/index.tsx и src/app/explore.tsx. Файл верстки в src/app/_layout.tsx настраивает навигатор вкладки, используя компонент AppTabs, специфичный для платформы.
src/компоненты - Содержит компоненты React Native, такие как тематический text.tsx, который создает текстовые элементы, использующие цветовую схему приложения в светлом и темном режимах. Некоторые компоненты имеют специфические для платформы варианты, использующие расширение .native.tsx для нативного и по умолчанию .tsx для веба (например, animated-icon.tsx и app-tabs.tsx).
src/константы - Содержит тема.ts, который определяет цвета, шрифты и константы интервала, используемые во всем приложении.
src/крючки - Содержит Реагировать Крючки, что позволяет совместно использовать общее поведение между компонентами. Например, например, useTheme() это крючок, возвращающий акту темы и useColorScheme() Обнаруживает цветовую схему пользователя. Некоторые крючки имеют специфические для платформы варианты с использованием .web.ts Расширение.
активы - В каталоге активов содержится каталог expo.icon для значка приложения iOS и подкаталог изображений с адаптивными значками Android (android-icon-foreground.png, android-icon-background.png, android-icon-monochrome.png), splash-icon.png для экрана брызг, favicon.png для веб-сайта.
Сценарии - Содержит reset-project.js, который можно управлять с npm run reset-project. Этот сценарий будет двигать src и Сценарии Каталоги для /пример, и создать новый src/приложение Каталог с a index.tsx и _layout.tsx Файл.
app.json - Содержит параметры конфигурации для проекта и называется конфигурацией приложения. Эти опции меняют поведение вашего проекта при разработке, создании, отправке и обновлении вашего приложения.
package.json - Файл package.json содержит зависимости проекта, сценарии и метаданные. В любое время, когда в ваш проект будет добавлена новая зависимость, она будет добавлена в этот файл.
tsconfig.json - Содержит правила, которые TypeScript будет использовать для обеспечения безопасности типа на протяжении всего проекта.

Тема: Следующие шаги
Сбросить свой проект
Вы можете удалить код шаблона и начать все заново с новым проектом. Запустите следующую команду для сброса вашего проекта:
npm run reset-project
Эта команда переместит существующие файлы в приложении в app-пример, а затем создаст новый каталог приложений с новым файлом index.tsx.

Тема: Инструменты для развития
Когда вы создаете новый проект с Expo, изучение следующих основных инструментов и веб-сайтов может помочь вам во время вашего путешествия по разработке приложения. На этой странице представлен обзор списка рекомендуемых инструментов.

Expo CLI является инструментом разработки и устанавливается автоматически с expo Пакет при создании нового проекта. Вы можете использовать его, используя npx (беседущий пакет Node.js).
Он предназначен для того, чтобы помочь вам быстрее двигаться на этапе разработки приложения. Например, ваше первое взаимодействие с Expo CLI - это запуск сервера разработки с запуском команды: npx expo start.
Ниже приведен список общих команд, которые вы будете использовать с Expo CLI при разработке своего приложения:
npx expo start	- Запуск сервера разработки (независимо от того, используете ли вы сборку разработки или Expo Go).
npx expo prebuild	- Генерирует нативные каталоги Android и iOS с использованием Prebuild.
npx expo run:android	- Составляет нативное приложение для Android локально.
npx expo run:ios	- Компилизирует собственное приложение для iOS локально.
npx expo install package-name	- Используется для установки новой библиотеки или проверки и обновления определенных библиотек в вашем проекте путем добавления --fix Вариант этой команды.
npx expo lint	- Настройка и настройка ESLint. Если ESLint уже настроен, эта команда закроет ваши файлы проекта.
В двух словах, Expo CLI позволяет вам разрабатывать, компилировать, запускать приложение и многое другое. См. ссылку на Expo CLI для получения более доступных опций и действий, которые вы можете выполнить с CLI.

EAS CLI используется для входа в вашу учетную запись Expo и компиляции вашего приложения с использованием различных услуг EAS, таких как сборка, обновление или отправка. Вы также можете использовать этот инструмент для:
    Опубликуйте свое приложение в магазинах приложений
    Создайте разработку, предварительный просмотр или производственное тело вашего приложения
    Создавайте обновления по воздуху (OTA)
    Управляйте своими учетными данными приложения
    Создайте специальный профиль для устройства iOS

Чтобы использовать EAS CLI, вам необходимо установить его глобально на локальной машине, выполнив команду:
npm install --global eas-cli
Вы можете использовать eas --help в окне терминала, чтобы узнать больше о доступных командах. Для полной ссылки, см. eas-cli npm страница.

Expo Doctor - это инструмент командной строки, используемый для диагностики проблем в вашем проекте Expo. Чтобы использовать его, запустите следующую команду в корневом каталоге вашего проекта:
npx expo-doctor
Эта команда выполняет проверки и анализ кодовой базы вашего проекта на предмет общих проблем в файлах config и package.json, совместимости зависимостей, конфигурационных файлов и общего состояния проекта. Как только проверка завершена, Expo Doctor выведет результаты.
Если Expo Doctor находит проблему, он предоставляет описание проблемы вместе с советами о том, как ее исправить или где найти помощь.
По умолчанию Expo Doctor проверяет пакеты вашего проекта против Реагировать родной каталог и проверяет, правильно ли синхронизируются свойства конфигурирования приложения, когда существуют собственные каталоги. Вы можете настроить эти проверки в вашем проекте package.json Файл. Смотреть reactNativeDirectoryCheck и appConfigFieldsNotSyncedCheck Для более подробной информации.
Вы также можете использовать npx expo-doctor --help для отображения информации об использовании.

Orbit - это приложение macOS, Windows и Linux, которое позволяет:
    Установка и запуск сборки из EAS на физических устройствах и эмуляторах.
    Установить и запустить обновления от EAS на Android Emulators или iOS Simulators.
    Запуск закусочных на Android Emulators или iOS Simulators.
    Используйте локальные файлы для установки и запуска приложений. Orbit поддерживает любые Android .apk, совместимые с iOS Simulator .app или специальные приложения с подписью ad hoc.
    Смотрите список прикрепленных проектов с вашей панели мониторинга EAS.

Вы можете скачать Orbit с Homebrew для macOS или непосредственно из релизов GitHub.
brew install expo-orbit
Если вы хотите, чтобы Orbit запускалась при автоматическом входе, щелкните значок Orbit в строке меню, затем «Настройки» и выберите опцию «Запустить в систему».

Expo Tools - это расширение VS-кода для улучшения вашего опыта разработки при работе с файлами настройки приложений. Он предоставляет такие функции, как автозаполнение и интеллектуальность для файлов, таких как конфигурация приложений, конфигурация EAS, конфигурация магазина и файлы конфигурирования модуля Expo.

Snack - это среда разработки в браузере, которая работает аналогично Expo Go. Это отличный способ поделиться фрагментами кода и поэкспериментировать с React Native без загрузки каких-либо инструментов на ваш компьютер.
Чтобы использовать его, перейдите в snack.expo.dev, редактировать <Text> компонент в App.js, выберите платформу (Android, iOS или веб) в правой панели и посмотрите изменения в прямом эфире.

Expo Go - это бесплатная игровая площадка с открытым исходным кодом для студентов и учащихся, чтобы попробовать React Native. Работает с Android и iOS.
Для получения дополнительной информации о том, как его использовать:
    Нажмите на эту ссылку, чтобы перейти к руководству по окружающей среде
    Выберите платформу для разработки в разделе Где вы хотели бы развиваться?
    Выберите Expo Go under Как бы вы хотели развиваться?
    Следуйте инструкциям, описанным в этом руководстве
    Примечание: Expo Go ограничена и не полезна для строительных проектов производственного класса. development buildsВместо этого используйте разработку.

The expo-go КЛИ Это автономный инструмент, который загружает бинарный автомат Expo Go для платформы и конкретной версии SDK или печатает его URL-адрес загрузки. Пропустите версию SDK, чтобы прикрепить конкретный выпуск, или опустите его для последнего выпуска, и укажите платформу для загрузки правильного двоичного устройства.
npx expo-go download android latest
npx expo-go url ios latest
Эта команда загружает приложение Expo Go в текущий каталог и кэширует его под ~/.expo.

Реагировать родной каталог
Любая библиотека, совместимая с React Native, работает в проекте Expo, когда вы используете сборку разработки для создания своего проекта.
reactnative.directory - это поисковая база данных для библиотек React Native. Если библиотека, которую вы ищете, не включена в Expo SDK, используйте каталог, чтобы найти совместимую библиотеку для вашего проекта.

Тема: Навигация в приложениях Expo и React Native
Базовая библиотека React Native не включает в себя встроенное навигационное решение, поэтому вы можете выбрать навигационную библиотеку, которая наилучшим образом соответствует вашим потребностям. Для приложений Expo и React Native это, как правило, выбор между React Navigation или Expo Router.

React Native main включает в себя основные компоненты пользовательского интерфейса, сенсорную обработку, API устройств и сетевое взаимодействие, но исключает, среди прочего, хранение, камеру, карты, большинство датчиков устройства и navigationнавигацию! Они предназначены для охвата общинных библиотек.

React Navigation - это навигационная библиотека на основе компонентов, широко используемая в экосистеме React Native. Он позволяет полностью сочинять навигаторы стека, вкладки и ящика в коде, чтобы вы могли реализовывать сложные потоки, пользовательские переходы и шаблоны UX-специфических приложений.
Библиотека предлагает внешний вид и ощущение, специфичный для платформы, с плавной анимацией и жестами, унифицированной мобильной и веб-маршрутизацией, автоматическими глубокими ссылками, маршрутами типа со статической конфигурацией и очень настраиваемым.

Expo Router - это файловая библиотека маршрутизации для проектов Expo и React Native. Следуя конвенции каталога приложений, он превращает файлы в маршруты и интегрируется с Expo для Expo CLI и комплектации без дополнительной настройки. В библиотеке также добавлены такие функции, как набранные маршруты, динамические маршруты, ленивое сочетание в разработке, статический рендеринг для Интернета и автоматическое глубокое связывание.
